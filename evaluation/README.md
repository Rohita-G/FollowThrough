# Evaluation Methodology & Metrics

This directory explains the evaluation framework for FollowThrough, disentangling programmatic weak-label agreement from human-annotated ground-truth verification.

---

## 1. Weak-Label Evaluation vs. Human Ground-Truth Evaluation

A fundamental methodological distinction in FollowThrough is the difference between **weak-label agreement** and **human-verified model accuracy**:

| Dimension | Full-Corpus Weak-Label Evaluation | Human Ground-Truth Evaluation |
|---|---|---|
| **Dataset Size** | 9,657 held-out test messages (from 97,988 retained emails) | Held-out stratified sample (50 reviewed sample, target: 100–200) |
| **Label Source** | Deterministic linguistic rules & regular expressions | Manual human review & double-annotation |
| **Primary Purpose** | Validates corpus scale, thread-disjoint splitting, and learning dynamics | Measures real-world task detection quality free of rule artifacts |
| **Key Limitation** | Susceptible to weak-supervision label noise and circular pattern bias | Smaller sample size due to manual annotation cost |

---

## 2. Empirical Benchmark Metrics (Full Held-out Test Split, N=9,657)

Both classification models were evaluated on the exact same thread-disjoint held-out test split of 9,657 messages. The empirical results recorded during training are:

| Metric | Model A: TF-IDF + Logistic Regression | Model B: Fine-tuned DistilBERT (5,000 steps) |
|---|---|---|
| **Exact Match Accuracy** | **0.8801** | 0.7145 |
| **Hamming Loss** | **0.0630** | 0.1479 |
| **Macro-F1** | **0.6874** | 0.3656 |
| **Micro-F1** | **0.8708** | 0.7027 |
| **Request Precision** | **0.8996** | 0.6801 |
| **Request Recall** | **0.9169** | 0.7906 |
| **Request F1** | **0.9081** | 0.7312 |
| **Commitment Precision**| **0.4286** | 0.0000 |
| **Commitment Recall** | **0.5124** | 0.0000 |
| **Commitment F1** | **0.4668** | 0.0000 |
| **Inference Time (Test)** | 0.02s | 57.57s (Apple MPS) |
| **Model Size** | **0.52 MB** | 255.4 MB |

### Analysis & Discussion of Discrepancy:
1. **TF-IDF Advantage on Pseudo-Labels:** Because the full-corpus labels were generated using transparent linguistic n-gram heuristics, the TF-IDF feature extractor (which learns exact n-gram associations like `please send`, `review`, `i will`) naturally achieved high agreement with the weak supervisor (Macro-F1 0.6874).
2. **DistilBERT Behavior:** DistilBERT learned the dominant **Request** class effectively (F1 0.7312, 79.1% recall). However, because **Commitments** represent only ~3.8% of the dataset, 5,000 steps of fine-tuning without extreme class reweighting caused the transformer to predict commitment conservatively, yielding zero true positives on the rare pseudo-label.
3. **Key Takeaway:** High agreement with weak rules does not imply human perfection. This empirical finding reinforces the necessity of FollowThrough's non-gating architecture: models provide supporting scores, but rule-based extraction operates independently across the full message text.

## 3. Human Evaluation Protocol

To validate genuine conversational task understanding, FollowThrough defines a dedicated human evaluation protocol:

### A. Task & Directive Extraction Evaluation
- **Task Identification Precision & Recall:** Comparing system-extracted action sentences against human-identified commitments/requests.
- **Span Overlap (Jaccard Overlap):** Measuring exact evidence boundary match.
- **Explicit Owner Accuracy:** Comparing extracted assignees (`Unspecified`, speaker pronoun, or proper name) against human gold.
- **Deadline Accuracy:** Comparing literal temporal expressions against human gold.

### B. Semantic Follow-up Linking Evaluation
- **Mean Reciprocal Rank (MRR):** Measuring rank position of the correct parent task given a follow-up message.
- **Hit@1 & Hit@3:** Frequency with which the true parent task appears within the top-1 or top-3 candidates generated by `all-MiniLM-L6-v2`.

## 4. Running Model Evaluation

To display the verified benchmark comparison table:
```bash
python3 scripts/evaluate_models.py
```

To evaluate predictions against a human-annotated CSV:
```bash
python3 scripts/evaluate_models.py --csv path/to/human_annotations.csv
```
